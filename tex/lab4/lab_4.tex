\subsection{Метод bootstrap}

Пусть дана выборка \(X_1, X_2, \dots, X_n\) из распределения \(F\), и требуется построить доверительный интервал для параметра \(\theta\).

\begin{enumerate}
\item Сначала вычисляется точечная оценка \(\widehat{\theta}_n = T(X_1,\dots,X_n)\). Если эта статистика состоятельна, то
\[
\widehat{\theta}_n \xrightarrow{P} \theta, \qquad n \to \infty.
\]

\item  генерируются выборки  
\[
\widehat{F}_n(x)=\frac{1}{n}\sum_{i=1}^{n}\mathbf{1}\{X_i \le x\}.
\]
По теореме Гливенко--Кантелли
\[
\sup_x |\widehat{F}_n(x)-F(x)| \xrightarrow{a.s.} 0,
\]

\item Для каждой выборки вычисляется нова оценка
\[
\theta_i^* = T(X_1^{*(i)}, X_2^{*(i)}, \dots, X_n^{*(i)}).
\]

\item После сортировки оценок доверительный-интервал строится: Если \(\gamma\)  доверительный уровень, \(\alpha = 1 - \gamma\) :
\[
\left(
\theta^*_{\left(\left\lfloor \frac{\alpha}{2}k \right\rfloor\right)},
\theta^*_{\left(\left\lceil \left(1-\frac{\alpha}{2}\right)k \right\rceil\right)}
\right).
\]
\end{enumerate}

В работе использовались параметры
\[
\gamma = 0.95, \qquad k = 10000.
\]

Собственная реализация percentile-bootstrap имеет вид:

\begin{lstlisting}
def bootstrap_percentile(sample, estimator, confidence_level=0.95,
                         n_resamples=9999, random_state=0):
    sample = np.asarray(sample)
    n = sample.size
    rng = np.random.default_rng(random_state)

    theta_hat = float(estimator(sample))
    bootstrap_estimates = np.empty(n_resamples, dtype=float)

    for i in range(n_resamples):
        bootstrap_sample = rng.choice(sample, size=n, replace=True)
        bootstrap_estimates[i] = float(estimator(bootstrap_sample))

    bootstrap_estimates.sort()
    alpha = 1.0 - confidence_level
    lower_rank = max(1, int(np.floor(alpha / 2.0 * n_resamples)))
    upper_rank = min(n_resamples, int(np.ceil((1.0 - alpha / 2.0) * n_resamples)))

    return {
        "estimate": theta_hat,
        "confidence_interval": (
            float(bootstrap_estimates[lower_rank - 1]),
            float(bootstrap_estimates[upper_rank - 1]),
        ),
    }
\end{lstlisting}

Для сравнения использовалась встроенная функция из \texttt{SciPy}:

\begin{lstlisting}
result = st.bootstrap(
    (np.asarray(sample),),
    estimator,
    n_resamples=n_resamples,
    confidence_level=confidence_level,
    method="percentile",
    vectorized=False,
    random_state=random_state,
)
\end{lstlisting}

\section{Состоятельные оценки параметров}

Обозначим
\[
\overline{X} = \frac{1}{n}\sum_{i=1}^{n}X_i,
\qquad
S_n^2 = \frac{1}{n}\sum_{i=1}^{n}(X_i-\overline{X})^2.
\]
По закону больших чисел
\[
\overline{X} \xrightarrow{P} EX,
\qquad
S_n^2 \xrightarrow{P} \mathrm{D}(X).
\]
Далее используется теорема о непрерывном отображении.

\subsection[Равномерное распределение U(a,b)]{Равномерное распределение \(U(a,b)\)}

Для равномерного распределения
\[
EX = \frac{a+b}{2},
\qquad
\mathrm{D}(X)=\frac{(b-a)^2}{12}.
\]
Отсюда оценки методом моментов имеют вид
\[
\widehat{a} = \overline{X} - \sqrt{3S_n^2},
\qquad
\widehat{b} = \overline{X} + \sqrt{3S_n^2}.
\]
% Так как это непрерывные функции от \((\overline{X}, S_n^2)\), оценки \(\widehat{a}\) и \(\widehat{b}\) являются состоятельными.

\subsection[Распределение Бернулли Bernoulli(p)]{Распределение Бернулли \(Bernoulli(p)\)}

В этом случае
\[
EX = p,
\]
поэтому естественная оценка
\[
\widehat{p} = \overline{X}
\]
% состоятельна напрямую по закону больших чисел.

\subsection[Биномиальное распределение Bin(m,p)]{Биномиальное распределение \(Bin(m,p)\)}

Для биномиального распределения
\[
EX = mp,
\qquad
\mathrm{D}(X)=mp(1-p).
\]
Решая систему уравнений метода моментов, получаем
\[
\widehat{m} = \frac{\overline{X}^{2}}{\overline{X} - S_n^2},
\qquad
\widehat{p} = \frac{\overline{X}}{\widehat{m}}.
\]
Поскольку
\[
(\overline{X}, S_n^2) \xrightarrow{P} (mp, mp(1-p)),
\]
имеем \(\widehat{m} \xrightarrow{P} m\) и \(\widehat{p} \xrightarrow{P} p\). 

\subsection[Нормальное распределение N(mu,sigma^2)]{Нормальное распределение \(N(\mu,\sigma^2)\)}

Для нормального распределения использовались оценки
\[
\widehat{\mu} = \overline{X},
\qquad
\widehat{\sigma} = \sqrt{S_n^2}.
\]
