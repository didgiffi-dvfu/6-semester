\section*{Биномиальное распределение}


\[
X_1,\dots,X_n \sim Bin(k,p),
\]
где \(k \in \mathbb{N}\), \(0<p<1\), а функция вероятности имеет вид
\[
\operatorname{P}(X=x)=\operatorname{C}_{k}^{x}p^x(1-p)^{k-x}, \quad x=0,1,\dots,k.
\]

Для биномиального распределения математическое ожидание и дисперсия равны:
\[
\operatorname{E}X = kp,
\qquad
\operatorname{D}(X)=kp(1-p).
\]

\section*{Оценка параметров распеределения Биномиаль-
ного методом  моментов}

Обозначим выборочное среднее и выборочную дисперсию с делением на \(n\):
\[
\overline{X}=\frac{1}{n}\sum_{i=1}^{n}X_i,
\qquad
s_n^2=\frac{1}{n}\sum_{i=1}^{n}(X_i-\overline{X})^2.
\]
\[
\overline{X}=kp,
\qquad
s_n^2=kp(1-p).
\]

Из первого равенства:
\[
k=\frac{\overline{X}}{p}.
\]

Подставим это во второе:
\[
s_n^2=\frac{\overline{X}}{p}p(1-p)=\overline{X}(1-p).
\]

Тогда
\[
\hat p_{\text{ММ}} = 1-\frac{s_n^2}{\overline{X}}.
\]

После этого
\[
\hat k_{\text{ММ}}=\frac{\overline{X}}{\hat p_{\text{ММ}}}
=
\frac{\overline{X}^2}{\overline{X}-s_n^2}.
\]

Итак оценки методом моментов:
\[
\boxed{
\hat p_{\text{ММ}} = 1-\frac{s_n^2}{\overline{X}},
\qquad
\hat k_{\text{ММ}} = \frac{\overline{X}^2}{\overline{X}-s_n^2}
}
\]

\section*{Оценка параметров распеределения Биномиального методом  максимального правдоподобия}

\[
L(k,p)=\prod_{i=1}^{n}\operatorname{C}_{k}^{x_i}p^{x_i}(1-p)^{k-x_i}.
\]

Логарифмическая функция правдоподобия:
\[
\ell(k,p)=
\sum_{i=1}^{n}\ln\operatorname{C}_{k}^{x_i}
+
\left(\sum_{i=1}^{n}x_i\right)\ln p
+
\left(nk-\sum_{i=1}^{n}x_i\right)\ln(1-p).
\]

При фиксированном \(k\) найдём максимум по \(p\):
\[
\frac{\partial \ell}{\partial p}
=
\frac{\sum x_i}{p}
-
\frac{nk-\sum x_i}{1-p}=0.
\]

После преобразований получаем:
\[
\hat p(k)=\frac{\overline{X}}{k}.
\]

Следовательно, ММП-оценка параметра \(p\) при фиксированном \(k\) имеет явный вид:
\[
\boxed{\hat p_{\text{ММП}}(k)=\frac{\overline{X}}{k}.}
\]

Для параметра \(k\) явной формулы нет, так как \(k\) должен быть целым и входит в биномиальные коэффициенты. Поэтому его ищут по профильной логарифмической функции правдоподобия:
\[
\hat k_{\text{ММП}}=
\arg\max_{k\in\mathbb{N},\,k\ge x_{\max}}
\left[
\sum_{i=1}^{n}\ln\operatorname{C}_{k}^{x_i}
+
n\overline{X}\ln\left(\frac{\overline{X}}{k}\right)
+
n(k-\overline{X})\ln\left(1-\frac{\overline{X}}{k}\right)
\right].
\]

После нахождения \(\hat k_{\text{ММП}}\) параметр \(p\) вычисляется по формуле
\[
\hat p_{\text{ММП}}=\frac{\overline{X}}{\hat k_{\text{ММП}}}.
\]

import math
import numpy as np

def mom_estimate(sample):
    x = np.asarray(sample)
    mean = x.mean()
    var_n = ((x - mean) ** 2).mean()
    p_hat = 1 - var_n / mean
    k_hat = mean / p_hat
    return k_hat, p_hat

def mle_estimate(sample, k_max=100):
    x = np.asarray(sample)
    n = len(x)
    s = int(x.sum())
    mean = s / n
    x_max = int(x.max())

    best_k = None
    best_ll = None

    for k in range(x_max, k_max + 1):
        p = mean / k
        if not (0 < p < 1):
            continue

        ll = sum(
            math.lgamma(k + 1)
            - math.lgamma(int(xi) + 1)
            - math.lgamma(k - int(xi) + 1)
            for xi in x
        )
        ll += s * math.log(p) + (n * k - s) * math.log(1 - p)

        if best_ll is None or ll > best_ll:
            best_ll = ll
            best_k = k

    return best_k, mean / best_k

rng = np.random.default_rng(7)
k_true, p_true = 10, 0.43

sample_100 = rng.binomial(k_true, p_true, 100)
sample_10000 = rng.binomial(k_true, p_true, 10000)

print("MM, n=100:", mom_estimate(sample_100))
print("MLE, n=100:", mle_estimate(sample_100))
print("MM, n=10000:", mom_estimate(sample_10000))
print("MLE, n=10000:", mle_estimate(sample_10000))
