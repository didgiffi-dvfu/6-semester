\section{Задача}

Целью данной работы является изучение и реализация z-теста и t-теста для среднего нормальной генеральной совокупности.

\subsection{Случай известной дисперсии}

Если \(X_1, X_2, \dots, X_n\) --- выборка из нормального распределения \(N(\mu,\sigma^2)\), где \(\sigma\) известно, то для гипотез
\[
H_0:\mu=\mu_0,
\qquad
H_1:\mu \vee \mu_0,
\qquad
\vee \in \{<,>,\neq\}
\]
используется статистика
\[
Z=\frac{(\overline{X}-\mu_0)\sqrt{n}}{\sigma}\sim N(0,1).
\]

\subsection{Расчёт p}

 \(\Phi(z)\) - функция распределения стандартного нормального закона. Тогда
\[
p=
\begin{cases}
1-\Phi(z), & H_1:\mu>\mu_0,\\
\Phi(z), & H_1:\mu<\mu_0,\\
2\Phi(-|z|), & H_1:\mu\neq\mu_0.
\end{cases}
\]

\[
\Phi_0(z)=P(0<Z<z).
\]

% Тогда при \(z>0\)
% \[
% p=0.5-\Phi_0(z).
% \]

% Для задачи 1:
% \[
% p=1-\Phi(z)=0.5-\Phi_0(z).
% \]

% \(p\)-значение равно
% \[
% 0.001349898\ldots
% \]

\subsection{Случай неизвестной дисперсии}

Если дисперсия неизвестна, то ищполюзется исправленное выборочное стандартное отклонение
\[
S=\sqrt{\frac{1}{n-1}\sum_{i=1}^{n}(X_i-\overline{X})^2}
\]
и формула Стьюдента
\[
T=\frac{(\overline{X}-\mu_0)\sqrt{n}}{S}\sim t_{n-1}.
\]
 \[H_1:\mu\neq\mu_0\]
\[
p=2F_{t_{n-1}}(-|t|),
\]
где \(F_{t_{n-1}}\) - функция распределения  Стьюдента с \(n-1\) степенями свобод

\subsection{Собственная функция}



\begin{lstlisting}
def mean_test_pvalue(sample=None, *, mu0, alternative="two-sided",
                     std=None, sample_mean=None, n=None):
    if std is not None:
        z = (sample_mean - mu0) * math.sqrt(n) / std
        if alternative == "greater":
            return 1 - st.norm.cdf(z)
        if alternative == "less":
            return st.norm.cdf(z)
        return 2 * st.norm.cdf(-abs(z))

    sample = np.asarray(sample, dtype=float)
    x_bar = np.mean(sample)
    s = np.std(sample, ddof=1)
    t = (x_bar - mu0) * math.sqrt(sample.size) / s
    return 2 * st.t.cdf(-abs(t), df=sample.size - 1)

\end{lstlisting}

\section{Решение задачи 1}

Дано:
\[
\mu_0=0.50,\qquad \overline{x}=0.53,\qquad n=121,\qquad \sigma=0.11,\qquad \alpha=0.01.
\]

 гипотезы
\[
H_0:a=0.50,
\qquad
H_1:a>0.50.
\]

% Т.к генеральное стандартное отклонение известно, применяется \(Z\)-критерий:
% \[
% Z=\frac{(\overline{x}-\mu_0)\sqrt{n}}{\sigma}
% =\frac{(0.53-0.50)\sqrt{121}}{0.11}
% =\frac{0.03\cdot 11}{0.11}
% =3.0000.
% \]

% Для правосторонней альтернативы
% \[
% p=1-\Phi(3.0000)=0.001350.
% \]

% Если пользоваться таблицей Лапласа, то
% \[
% \Phi_0(3)=0.498650102,
% \qquad
% p=0.5-\Phi_0(3)=0.5-0.498650102=0.001349898.
% \]

% Критическое значение:
% \[
% z_{1-\alpha}=z_{0.99}=2.3263.
% \]

% Так как
% \[
% Z=3.0000>2.3263
% \qquad\text{и}\qquad
% p=0.001350<0.01,
% \]
% нулевая гипотеза отвергается.

% \textbf{Решение:}

\begin{lstlisting}
pvalue = mean_test_pvalue(
    mu0=0.50,
    alternative="greater",
    std=0.11,
    sample_mean=0.53,
    n=121,
)
print(f"p-значение = {pvalue}, выполнение H_0: {pvalue > 0.01}")
\end{lstlisting}

% \textbf{Вывод в консоли:}

\begin{lstlisting}
p-значение = 0.0013498980316301035, выполнение H_0: False
\end{lstlisting}

\textbf{Ответ:} Так как \(p\)-значение \(< \alpha = 0.01\), гипотезу \(H_0\) отвергаем.

% Развёрнутая выборка имеет объём
% \[
% n=2+3+4+6+5=20.
% \]

% Выборочное среднее:
% \[
% \overline{x}=\frac{\sum n_i x_i}{\sum n_i}
% =\frac{34.8\cdot 2+34.9\cdot 3+35.0\cdot 4+35.1\cdot 6+35.3\cdot 5}{20}
% =35.07.
% \]

% Так как генеральная дисперсия неизвестна, используем \(t\)-критерий Стьюдента. Сначала найдём исправленную выборочную дисперсию:
% \begin{align*}
% S^2
% &=\frac{1}{n-1}\sum_{i=1}^{k} n_i(x_i-\overline{x})^2 \\
% &=\frac{1}{19}\Bigl(
% 2(34.8-35.07)^2+
% 3(34.9-35.07)^2+
% 4(35.0-35.07)^2+ \\
% &\qquad\qquad
% 6(35.1-35.07)^2+
% 5(35.3-35.07)^2
% \Bigr).
% \end{align*}

% После вычисления получаем
% \[
% S^2=0.027474,
% \qquad
% S=\sqrt{0.027474}=0.165752.
% \]

% Теперь вычислим статистику:
% \[
% T=\frac{(\overline{x}-\mu_0)\sqrt{n}}{S}
% =\frac{(35.07-35)\sqrt{20}}{0.165752}
% =1.8887.
% \]

% Для двусторонней альтернативы и \(19\) степеней свободы
% \[
% p=2F_{t_{19}}(-|1.8887|)=0.074301.
% \]

% Критическое значение:
% \[
% t_{1-\alpha/2;19}=t_{0.975;19}=2.0930.
% \]

% Так как
% \[
% |T|=1.8887<2.0930
% \qquad\text{и}\qquad
% p=0.074301>0.05,
% \]
% нет оснований отвергать нулевую гипотезу.

% Для проверки результата использована встроенная функция \texttt{ttest\_1samp} из модуля \texttt{scipy.stats}. Она дала те же значения:
% \[
% T_{\text{SciPy}}=1.8887,
% \qquad
% p_{\text{SciPy}}=0.074301.
% \]

% \textbf{Решение:}

\begin{lstlisting}
X_n = [34.8] * 2 + [34.9] * 3 + [35.0] * 4 + [35.1] * 6 + [35.3] * 5

pvalue = mean_test_pvalue(X_n, mu0=35, alternative="two-sided")
