# Этап 2. Сравнение подходов для прогнозирования двух неизвестных

На этом этапе нужно сопоставить несколько вариантов решения задачи с двумя неизвестными функциями.

## Что требуется сделать

1. Сравнить полученный график сходимости с результатами первого этапа.
2. Реализовать подстановку в исходной системе.
3. Учесть, что максимальный порядок производной в полученной системе равен 2, и дополнительно задать граничные условия для `v`.
4. Реализовать три варианта нейросетевой модели:
   - одна сеть с двумя выходными нейронами (`u` и `v`);
   - отдельные сети, где каждая предсказывает только одну неизвестную;
   - кастомная архитектура с общим (или несколькими общими) слоями и раздельными выходами для каждой неизвестной.
5. Построить графики функции потерь для каждого подхода и выполнить сравнительный анализ.
